# Render deployment — LogFix AI V2.1

Two distinct configurations are supported. **Use the public synthetic demo first.** Real-cloud administration on a shared public URL is **not** recommended without another authentication layer.

## A. Public demo (free)

1. Extract the ZIP and create a GitHub repo with the **contents** at its root: `Dockerfile`, `render.yaml`, `frontend/`, `backend/`, `docs/`.
2. Check files for embedded secrets and do not commit `.env`, service-account JSON, API keys, or token values.
3. In Render [Dashboard](https://dashboard.render.com), New → Web Service, connect your GitHub repo; choose Docker runtime, `./Dockerfile`, root directory blank, **Free** plan, `/health` health check.
4. Configure these Render Environment values:

   ```env
   PUBLIC_DEMO_ONLY=true
   ENABLE_LLM=false
   AI_RCA_ON_RUN=false
   ```

   **No** `APP_ADMIN_KEY`, cloud credentials, OpenAI API key or database is necessary for the public demo.
5. Deploy and wait for the Build/Deploy logs to show success. Render assigns an HTTPS URL such as `https://<your-service>.onrender.com` (not known until deployment).
6. In your browser: Run & Schedule → **Run Now**; confirm sample logs; go to Log Explorer and Agent Monitor. RCA Archive, live cloud access and AI key editing remain locked for visitors.

## B. Private admin configuration (requires your own access control)

1. Create a **separate** deployment, protect it behind SSO/IAP/VPN or an equivalent access gateway, and set `PUBLIC_DEMO_ONLY=false`.
2. Generate a long `APP_ADMIN_KEY` using `python -c "import secrets; print(secrets.token_urlsafe(48))"`, configure it as a Render Environment secret.
3. Set least-privilege server environment secrets as described in `docs/CLOUD_ACCESS.md`. Browser-entered keys are RAM-only and are lost when Render Free spins down.
4. To persist RCA even when Render Free restarts, create an external PostgreSQL database and add its **private connection URL** as the Render `DATABASE_URL` secret. The app supports SQLAlchemy with `psycopg`; schema initializes on startup. SQLite files created on Render Free disappear on spin-down/redeploy. An external DB may have separate costs or free limits.
5. For model calls, set `OPENAI_API_KEY` in Render Environment, navigate to AI Settings, enable LLM, and optionally enable auto RCA. Check provider pricing before enabling scheduled model use.
6. After deploy, test connectivity one cloud at a time, run a private log collection, inspect RCA Archive and then validate database persistence across a restart.

**Do not expose real operational logs with only the current single shared admin key.** This MVP lacks per-user roles, MFA, an audit trail and enterprise security review.

## Free plan limitations

- Free Render services spin down after 15 minutes without inbound traffic; starting again can be slow.
- Local SQLite/RAM secrets are lost after spin-down/restart. External Postgres is required for durable RCA storage on a free hosting instance.
- **The in-process scheduler does NOT continue while the service sleeps**. Use always-on compute or a protected external scheduler for dependable 24/7 log monitoring. Render Cron Jobs are separately billed and not part of the free web service.
- Cloud logging API queries, model tokens and external DB/network usage can incur fees independently of Render hosting.

## Verify after deploy

```bash
curl https://YOUR-RENDER-URL/health
curl -X POST https://YOUR-RENDER-URL/api/demo/run
```

Expected: HTTP 200 and JSON with 12 synthetic log entries, 11 operations agent stages and three incidents. The actual URL is generated by Render. A missing/incorrect admin key must return HTTP 401 for `/api/admin/config`, and no public instance should allow `/api/admin/runs/start` even with an admin key if `PUBLIC_DEMO_ONLY=true`.

## Troubleshooting

- **Frontend build fails:** inspect npm logs; `npm install` and `npm run build` are executed in the Dockerfile with internet required.
- **Can't access UI locally:** run FastAPI only on port 8000 to see the included dependency-free HTML fallback, or build the full React frontend using `npm run build`.
- **Model check fails:** validate the key, model name, credits, API connectivity and enable switch. Do not paste keys into chats or tickets.
- **No logs:** test the provider connection, permissions, logging workspace/table/log group/project, correct region and last 30-minute window. A connected provider can return zero events.
- **Runs disappear after redeploy:** supply `DATABASE_URL` for external Postgres, not local SQLite on Render Free.
- **Schedules don't fire overnight:** free instance was asleep; this is expected.
